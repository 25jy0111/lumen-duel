# 現在のゲームルール（第一段階）

LUMEN DUEL（ルーメンデュエル）は、人間1人対CPU1人のオリジナルカードゲームです。God Fieldを参考にしていますが、完全再現ではありません。本書がこの実装のルールです。

## 初期値と勝利

- 両者HP40、MP10、所持金20、手札9枚。HP上限40、MP上限10、手札上限18枚。
- 先攻は50%ずつランダム。先攻決定後、各プレイヤーに配札します。
- 相手のHPを0にすると勝利。HPは0未満になりません。終了後は操作できず、新しいゲームで初期化します。
- 所持金は表示のみで、第一段階では変動しません。

## ターンと攻防

1. 自分のメイン行動で「攻撃」「回復」「祈る」「捨てる」のいずれか1回を行います。
2. 攻撃は通常武器ちょうど1枚＋追加武器0枚以上、または奇跡ちょうど1枚。通常武器同士、奇跡同士、奇跡と追加武器の併用は不可。
3. 攻撃宣言後、相手が防具0枚以上を選択。防具なしで受けることもできます。
4. ダメージは `max(0, 合計攻撃力 − 合計防御力)`。通常武器も奇跡も同じ防具で防げます。
5. 防御解決で勝敗を判定し、生存していれば防御側のメイン行動に移ります。防御そのものは次のメイン行動を消費しません。
6. 回復・祈る・捨てるは相手に応答させずターン終了。防御中はこれらを使えません。

ターン番号はメイン行動の交代ごとに1増えます。防御応答中は同じ番号です。任意のパスや自由な手札交換はありません。

## 消費と補充

- 通常武器・追加武器・防具・雑貨は使った枚数だけ消費し、同じ枚数を補充します。元の手札の少なさを9枚まで埋める処理はありません。
- 攻撃側の消費と補充は攻撃宣言時、防御側はダメージ計算後に処理します。致死ダメージ時も防御に使った札を補充してから終了します。
- 奇跡は必要MPを払って使用し、カードを手札に残して1枚引きます。使用のたびに同じ処理を行い、MP不足なら使えません。
- 上限18枚を超える分は引きません。手札の自動破棄・入れ替えはありません。
- 雑貨は自分のHPまたはMPを回復し、上限を超えません。該当資源が満タンなら使えません。防御応答は発生しません。

## 祈る・捨てる

- **祈る**：MPを含めて使用可能な攻撃または回復が1つもない場合だけ、1枚引いてターン終了。防具と追加武器しかない場合も祈れます。上限18枚の場合は手札を変えずにターン終了します。
- **捨てる**：自分のメイン行動として、手札から1枚以上を選んで捨て、ターン終了。補充なし。奇跡も捨てられます。
- 上限まで行動不能札が溜まっても捨てることで減らせます。空の手札では祈れます。防具がなくても防御なしで応答できるため、操作不能な局面はありません。

## CPU

- 可能なら被ダメージ0となる最小防御力の組合せを選び、同じ防御力なら少ない枚数を使います。不足時は防具をすべて使います。
- HP30以下ならHP回復を優先します。
- 最強の通常武器＋追加武器すべてと、使用可能な最強の奇跡を比較し、高い攻撃力を選びます。同値なら通常武器を選びます。
- 攻撃不能時は回復、祈るの順で検討します。手札が満杯で使用可能な行動がなければ全札を捨てます。捨てた分は補充しません。
- CPUも人間と同じ行動検証・エンジンで処理します。CPUは相手の手札内容を判断に使いません。

## 参考資料と暫定仕様

確認日：2026-11-12。

- [God Field公式](https://godfield.net/)：参照しましたが、取得できたページから細かな公式ルール本文は確認できませんでした。
- [非公式wiki「ゲームの仕様」](https://w.atwiki.jp/piong/pages/16.html)：初期HP・手札、ランダム先攻、消費数補充、攻防差、祈り、奇跡の再利用、独立抽選の参考。非公式資料であり、原作の正式仕様であるとは断定しません。
- [参考記事](https://idea427.hatenablog.com/entry/2023/07/31/192159)：奇跡使用で手札枠が増える説明を参考にしました。これも非公式資料です。

**この実装で決めた暫定仕様**：MP/HP回復上限、奇跡は学習済み領域を作らず手札に常駐して毎回1枚引くこと、奇跡の防具適用、通常武器の併用枚数、回復で1ターン消費、捨てるで1ターン消費、補充タイミング。原作の正式ルールとして扱わないでください。

**依頼に合わせた仕様**：祈る条件は「武器がない」ではなく「使用可能な攻撃・回復がない」。手札満杯で祈っても、非公式資料にあるランダム破棄・交換は採用しません。

未実装：取引、属性、状態異常、反射、連鎖、確率追加効果、オンライン、複数人対戦、終末の時などの強制決着。意図的に防御や破棄を繰り返す長期戦を強制終了する仕組みはありません。
